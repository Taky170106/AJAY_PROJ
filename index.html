Three-tier system architecture (FIG. 2 of the disclosure)

Patient Node — Edge Layer

ESP32 MCU · thermistor ±0.1 °C · optional SpO₂/pulse · BLE + Wi-Fi · 24–48 h Li-ion · mobile app for symptom entry.

→
Cloud Intelligence Layer

TLS 1.2/1.3 channel · time-series DB · AI engine (pattern recognition, LSTM forecast, RF/SVM severity) · alert dispatcher.

→
Clinician Node — Application Layer

RBAC web dashboard · triage ranking · alert centre · historical analytics & predictive graphs.
